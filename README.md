# MegaFon Deck — приватный плагин

> Внутренний инструмент. Репозиторий должен оставаться **приватным**: в нём шаблон и выдержки из брендбука МегаФона.

Презентации МегаФона в фирменном стиле одной командой:

```
/megafon-deck:deck <тема, тезисы или файлы>
```

На выходе `.pptx` (редактируется в PowerPoint, все слайды на фирменных макетах) и PDF. Рядом сохраняется `<имя>.deck.json`, поэтому правки — это пересборка, а не ручная перерисовка.

## Что внутри

| Часть | Что делает |
|---|---|
| `assets/template.pptx` | Фирменный шаблон: 3 оформления (светлое, зелёное, тёмное), 23 типа макетов. Цвета темы приведены к брендбуку 2026 |
| `assets/layout_roles.json`, `slotmaps/*.png` | Каталог макетов: какие поля есть и что в них писать; картинки с номерами полей |
| `assets/brand.json` | Константы брендбука: палитра, порядок цветов диаграмм, правила набора, логотип |
| `assets/icons/` | 135 линейных иконок Lucide (лицензия ISC) в 5 фирменных цветах |
| `scripts/build_deck.py` | Собирает .pptx из deck.json: макеты, нативные диаграммы и таблицы, иконки, нумерация, шапка, заметки, типографика |
| `scripts/lint_deck.py` | Проверяет шрифты, цвета, переполнение текста, остатки подсказок шаблона, типографику |
| `scripts/render.py` | PDF и PNG для визуальной проверки (LibreOffice или PowerPoint на Mac) |
| `skills/deck/SKILL.md` | Сценарий для Claude: план → сборка → проверка → выдача |

## Установка (приватный репозиторий)

**В приложении Claude (рекомендуется — синхронизируется и в Claude Code):**
1. https://claude.ai/customize/plugins → **Add** → **Add marketplace**.
2. Ввести `Elarhado/megafon-deck`. При запросе подключить GitHub и дать Claude GitHub App доступ к этому репозиторию.
3. Найти MegaFon Deck → **Add**. У маркетплейса включить **Sync automatically**.

**Или только в Claude Code (терминал):** нужен доступ git к приватному репозиторию (например, `gh auth login`).
```
claude plugin install megafon-deck --marketplace Elarhado/megafon-deck
```

**Зависимости на компьютере:** Python 3.9+ с `python-pptx` и `Pillow` (скилл предложит установить сам: `python3 -m pip install --user python-pptx pillow`). Для PDF — LibreOffice (`brew install --cask libreoffice`) или Microsoft PowerPoint на Mac.

## Где работает

| | Обычный чат | Задачи в десктопе | Claude Code |
|---|---|---|---|
| Скилл | загружается, но скриптам нужен компьютер | да | да |

Скрипты запускаются на компьютере, поэтому пользоваться нужно в задачах десктоп-приложения или в Claude Code.

## Решения по исходникам

- Цвета по брендбуку 2026: berry `AA5AFF` (в шаблоне было `B359FF`), night `1E64AA` (в брендбуке HEX и RGB расходятся), чёрный `000000`.
- В PowerPoint только Arial (брендбук, с. 30).
- Логотип не рисуется отдельно — он встроен в макеты обложек.

## Обновление ассетов

Новый шаблон от дизайнеров: `python3 tools/prepare_template.py <новый.pptx> assets && python3 tools/render_slotmaps.py assets`, затем `python3 -m unittest discover -s tests`. Если в новом шаблоне появятся новые макеты, их нужно добавить в `KEYS` в `tools/prepare_template.py` и в `assets/layout_roles.json`.

## Проверено

- 18 тестов: все 23 макета × 3 оформления, диаграммы, таблицы, иконки, валидация, типографика; Python 3.9 и 3.13.
- Независимая проверка кода (сборка, проверка ошибок ввода, типографика на 19 случаях, линтер, рендер).
